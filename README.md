# 미션 :  java-calculator-8

## 🔍 진행 방식
- 미션은 **기능 요구 사항**, **프로그래밍 요구 사항**, **과제 진행 요구 사항** 세 가지로 구성되어 있다.
- 기능을 구현하기 전에 **기능 목록을 먼저 작성**하고, **기능 단위로 커밋**하는 방식으로 진행한다.
- 기능 요구 사항에 명시되지 않은 내용은 스스로 판단하여 구현한다.

## 🧾 미션 제출 방법
- 미션 구현을 완료한 후 **GitHub을 통해 제출**해야 한다.
- GitHub 제출 후, **우아한테크코스 지원 플랫폼**에 PR 링크를 포함하여 최종 제출한다.
- 과제를 수행하면서 느낀 점이나 배운 점을 자유롭게 작성한다.

## ⚠️ 과제 제출 전 체크 리스트
- 기능을 올바르게 구현했더라도 **출력 형식을 지키지 않으면 0점 처리**된다.
- 제출 전 모든 테스트가 통과하는지 반드시 확인한다.
- 테스트가 실패할 경우 **0점 처리**된다.

## 🚀 기능 요구 사항
- 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 
기준으로 분리한 각 숫자의 합을 반환한다.
- 앞의 기본 구분자(쉼표, 콜론) 외에 커스텀 구분자를 지정할 수 있다. 커스텀 구분자는 
문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후
애플리케이션은 종료되어야 한다.

- 구분자와 커스텀 구분자 구분하는 메서드 제작
- 양수값을 저장하는 메서드 제작
- 예외 처리 제작
